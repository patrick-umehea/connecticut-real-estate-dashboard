# Connecticut Property Tax Intelligence Dashboard

##  Project Overview

This project analyzes real estate transactions across Connecticut to uncover insights related to property valuation and taxation.

---

##  Business Problem

Local governments depend on property taxes for revenue. However, poor timing and inaccurate property valuation can reduce efficiency.

This project explores:

* When transactions peak (tax opportunity)
* How accurately properties are valued (Sales Ratio)
* Which regions perform best

---

##  Analytical Approach

* Cleaned and structured real estate data
* Built data model (Town → County → Segment)
* Created measures (Avg Sales Ratio, Total Sales)
* Designed interactive Power BI dashboard

---

##  Key Insights

* Property transactions peak mid-year → optimal tax collection window
* Sales Ratio highlights over/undervalued regions
* High-performing towns show strong valuation efficiency

---

##  Dashboard Features

* Interactive filters (Year, County, Property Type)
* Geographic visualization
* Time trend analysis
* Top 10 towns by sales ratio
